How to get it working
  1. Upload this file to any website with https (your own hosting works). The sensor will not run from a file opened off the phone's storage.
  2. Open it in Chrome on Android.
  3. If the status says "Sensor not available", open chrome://flags, search for Generic Sensor Extra Classes, set it to Enabled and relaunch Chrome.
  4. iPhones are not supported. Safari does not give websites raw magnetometer readings, so an iPhone version needs a native app.

What the numbers mean: Earth's own field is roughly 25–65 µT (around 25–30 µT in South Africa). The meter watches for changes from your baseline. Wiring, appliances, speakers, steel and the phone itself moving all cause real spikes, so check the suggested cause before calling anything unexplained.
